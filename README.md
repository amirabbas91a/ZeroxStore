# ZeroxStore

**ZeroxStore** is a custom PlayStation Store-inspired homebrew store for jailbroken **PS5** consoles (`PPSA99059`), featuring a **Liquid Glass** UI, official PlayStation Store styling, and file-size badges on every game card.

## Features

- **PlayStation Store Aesthetic + Liquid Glass UI**: Deep PS5 midnight navy palette (`#070a12` / `#111829`), PlayStation Electric Blue accents (`#2e9bff` / `#7cc4ff`), translucent frosted glass surfaces, diagonal specular gradients, and animated liquid-glass focus rings.
- **Full Free Library with File Sizes**: Browse PS4 & PS5 titles with file sizes (`GB` / `MB`) displayed directly on game cards instead of prices.
- **Direct & Multi-Host Downloads**: Supports direct downloads and host-assisted captures (`archive.org`, `mediafire.com`, `buzzheavier.com`, `vikingfile.com`, `datanodes.to`, `filekeeper.net`, `rootz.so`, `akirabox.com`), plus ShadowMount installation.
- **Custom Branding**: Updated `icon0.png`, `pic0.png`, `pic1.png`, `param.json` (`ZeroxStore` / `UP9000-PPSA99059_00-ZEROXSTORE000000`), and in-app UI strings.

## Installation (PS5)

1. Download **`ZeroxStore.exfat`** from the [Latest Release](../../releases/latest).
2. Copy `ZeroxStore.exfat` to your PS5 (e.g., via USB or FTP) and mount/install it using your PS5 homebrew loader / ShadowMount / Itemzflow.
3. Alternatively, you can copy the extracted `[ZeroxStore]-[PPSA99059]` folder directly.
